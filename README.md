## Research focus
- Real-time semantic segmentation for unstructured road scenes (heterogeneous traffic, domain shift)
- Efficient perception on edge hardware (NVIDIA Jetson Nano and AGX)
- Current direction: communication-efficient cooperative perception for connected vehicles (feature sharing, temporal differential encoding; experiments on OPV2V in progress)

## Repositories
- [**IndiVnet**](https://github.com/Pritamresearch/IndiVnet): A region-adaptive semantic image segmentation network for autonomous driving in unstructured environments using progressive dilation.
- [**DOCOF**](https://github.com/Pritamresearch/DOCOF): Decomposed object-centric occupancy forecasting with bounded kinematic integration for stable long-horizon BEV prediction.
- [**realtime-road-risk**](https://github.com/Pritamresearch/realtime-road-risk): Real-time road risk assessment from a single camera: DA3 metric depth + YOLO26-seg + SegFormer-B2, late fusion, live dashboard.
